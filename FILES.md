## Restoring this project elsewhere

```bash
unzip zenith-panel.zip && cd zenith-panel
npm install            # dependencies + jsdom (dev)
npm start              # or: bash install.sh -y   (full host install)
npm run verify         # full verification run in a throwaway panel
```

`data/db.json` (accounts, servers, nodes, activity) and `data/java/` are runtime state:
copy them if you want to keep your existing setup, leave them out for a clean install.
